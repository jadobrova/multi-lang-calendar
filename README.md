# `>_ MULTI-LANG-CALENDAR`

A cross-language implementation of a simple console calendar. From Rust's zero-cost abstractions to Python's elegant simplicity.

## `[LANGUAGES_DEPLOYED]` 🗂️

| Language | Path | Run Command |
|:---|:---|:---|
| **C++** | `cpp/calendar.cpp` | `g++ calendar.cpp -o calendar && ./calendar` |
| **Java** | `java/Calendar.java` | `javac Calendar.java && java Calendar` |
| **C#** | `csharp/Calendar.cs` | `csc Calendar.cs && mono Calendar.exe` |
| **Go** | `go/calendar.go` | `go run calendar.go` |
| **Python** | `python/calendar.py` | `python calendar.py` |
| **JavaScript** | `javascript/calendar.js` | `node calendar.js` |
| **Rust** | `rust/calendar.rs` | `rustc calendar.rs && ./calendar` |
